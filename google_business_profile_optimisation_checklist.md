# Google Business Profile Optimisation Checklist

## 1. Business Information

-   [ ] Claim and verify the Google Business Profile.
-   [ ] Confirm the business name matches the real-world business name.
-   [ ] Confirm the correct business address and map pin.
-   [ ] Add the correct service area, where applicable.
-   [ ] Add the main business phone number.
-   [ ] Add accurate business hours and special/holiday hours.
-   [ ] Add relevant business attributes.

## 2. Categories

-   [ ] Select the most relevant primary category.
-   [ ] Research relevant secondary categories related to the primary
    category.
-   [ ] Add only categories that accurately describe what the business
    is.
-   [ ] Do not use categories simply as keyword targets.
-   [ ] Review and update categories when the business changes.

Google allows up to 9 additional categories. Categories should
accurately represent the business rather than individual keywords or
every service offered.

## 3. Social Profiles

-   [ ] Add Facebook.
-   [ ] Add Instagram.
-   [ ] Add LinkedIn where relevant.
-   [ ] Add YouTube, TikTok, Pinterest or X where relevant.
-   [ ] Make sure each profile is active and points to the correct
    business.

Google currently supports one social profile link per supported
platform, although availability varies by region and profile.

## 4. Website URL

-   [ ] Add the correct HTTPS website URL.
-   [ ] Confirm the URL works on mobile and desktop.
-   [ ] Use UTM tracking where appropriate:

``` text
https://example.com/?utm_source=google-business&utm_medium=organic
```

-   [ ] Confirm the UTM parameters are being recorded correctly in
    analytics.
-   [ ] Avoid creating indexing or canonicalisation issues with tracking
    URLs.

## 5. Business Description

-   [ ] Explain what the business offers.
-   [ ] Mention the main products/services.
-   [ ] Mention the location naturally where relevant.
-   [ ] Include genuine differentiators and trust signals.
-   [ ] Use important keywords naturally, without keyword stuffing.
-   [ ] Write for prospective customers first.
-   [ ] Keep the description within Google's 750-character limit.
-   [ ] Do not add URLs or promotional/sales-focused copy.

## 6. Photos & Videos

-   [ ] Add a high-quality logo.
-   [ ] Add a suitable cover photo.
-   [ ] Add exterior photos.
-   [ ] Add interior photos.
-   [ ] Add team/staff photos where appropriate.
-   [ ] Add product photos.
-   [ ] Add service/work photos.
-   [ ] Add location-specific photos.
-   [ ] Add videos where useful.
-   [ ] Use genuine, high-quality images.

### Photo File Naming

Use descriptive filenames:

``` text
Company_Name_City_Business_Category
```

Examples:

``` text
Bed_Studio_Auckland_Bed_Store.jpg
Signet_Motors_Auckland_Used_Car_Dealer.jpg
Quality_Care_Dental_Auckland_Dentist.jpg
```

-   [ ] Use descriptive filenames.
-   [ ] Include the business name where appropriate.
-   [ ] Include the relevant city/location.
-   [ ] Include the relevant business category or service.
-   [ ] Avoid generic filenames such as `IMG_1234.jpg`.

### Geo-Tagged Photos

-   [ ] Add relevant location metadata to original business photos where
    appropriate.
-   [ ] Use [GeoImgr](https://tool.geoimgr.com/) to add or verify GPS
    metadata if required.
-   [ ] Ensure coordinates represent the actual business/location.
-   [ ] Never use fake or unrelated coordinates.
-   [ ] Keep original image files backed up.

Geo-tagging should be treated as supporting image metadata, not a
replacement for accurate Business Profile information.

## 7. Google Business Profile FAQs

-   [ ] Add useful FAQs based on genuine customer questions.
-   [ ] Cover common products/services.
-   [ ] Cover quote, booking or pricing questions where appropriate.
-   [ ] Cover location/service-area questions.
-   [ ] Cover opening hours and booking questions.
-   [ ] Cover common pre-purchase questions.
-   [ ] Keep answers accurate and concise.
-   [ ] Avoid keyword-stuffed questions.

## 8. Reviews

-   [ ] Create a direct Google review link or QR code.
-   [ ] Ask genuine customers for reviews after a completed
    service/purchase.
-   [ ] Never buy or fabricate reviews.
-   [ ] Encourage genuine feedback.
-   [ ] Respond to positive reviews.
-   [ ] Respond professionally to negative reviews.
-   [ ] Monitor new reviews regularly.

## 9. Bing Places

-   [ ] Create or claim the business listing on Bing Places.
-   [ ] Keep business name, address, phone and website consistent.
-   [ ] Add the correct category.
-   [ ] Add photos and opening hours.
-   [ ] Verify the listing.
-   [ ] Use Bing Places' Google Business Profile import/sync option
    where applicable.

## 10. Apple Maps / Apple Business Connect

-   [ ] Create or claim the business through Apple Business Connect.
-   [ ] Confirm business name.
-   [ ] Confirm address and map location.
-   [ ] Add phone number.
-   [ ] Add website URL.
-   [ ] Add opening hours.
-   [ ] Add category information.
-   [ ] Add photos/logo where available.
-   [ ] Verify the business.
-   [ ] Check the listing in Apple Maps.

## 11. Local Business Schema

-   [ ] Add the most specific applicable `LocalBusiness` subtype.
-   [ ] Add business name.
-   [ ] Add website URL.
-   [ ] Add phone number.
-   [ ] Add physical address where applicable.
-   [ ] Add latitude/longitude where appropriate.
-   [ ] Add opening hours.
-   [ ] Add official logo and image.
-   [ ] Add social profiles using `sameAs`.
-   [ ] Keep schema consistent with visible website information.
-   [ ] Validate the schema after implementation.

## 12. NAP Consistency

Check the following across the website and major platforms:

-   [ ] Business name
-   [ ] Address
-   [ ] Phone number
-   [ ] Website URL
-   [ ] Opening hours
-   [ ] Business category

Check:

-   [ ] Google Business Profile
-   [ ] Bing Places
-   [ ] Apple Maps
-   [ ] Website
-   [ ] Social profiles
-   [ ] Industry directories
-   [ ] Local directories
-   [ ] Review websites

## 13. Final Quality Check

-   [ ] Profile is verified.
-   [ ] Primary and additional categories are correct.
-   [ ] Business name follows Google's guidelines.
-   [ ] Address/map pin is correct.
-   [ ] Service area is correct.
-   [ ] Opening hours are correct.
-   [ ] Website URL works.
-   [ ] UTM tracking works.
-   [ ] Social profiles are connected where available.
-   [ ] Business description is complete.
-   [ ] Photos are high quality and relevant.
-   [ ] Photo filenames are descriptive.
-   [ ] FAQs are useful and accurate.
-   [ ] Reviews are monitored and answered.
-   [ ] Bing Places is claimed and consistent.
-   [ ] Apple Maps is claimed and consistent.
-   [ ] Local Business schema is implemented.
-   [ ] NAP information is consistent.
-   [ ] Profile is checked on Google Search and Google Maps.
-   [ ] Website links from the profile are tested.
